# C# Fundamentals - Lecture 1 - Part 1

## 1. What is an Executable File (.exe)?

An **Executable File (.exe)** is a file that can be executed directly by the operating system.

A **.NET executable** contains:

* MSIL (Microsoft Intermediate Language)
* Metadata
* Manifest (Assembly information)

---

## 2. Build & Execution Flow

```text
C# Code
    ↓
C# Compiler
    ↓
.exe / .dll
(MSIL + Metadata + Manifest)
    ↓
CLR (Common Language Runtime)
    ↓
JIT Compiler
    ↓
Machine Code
    ↓
CPU
```

---

## 3. Compiler

**Definition**

* Converts **C# source code** into **MSIL**.
* Produces an **Assembly** (.exe or .dll).

---

## 4. MSIL (Microsoft Intermediate Language)

**Definition**

* An intermediate language generated by the C# compiler.
* It is **not** Machine Code.
* It is converted into Machine Code at runtime by the JIT compiler.

**Why MSIL?**

* Platform independence.
* Runtime optimization.
* Supports multiple .NET languages.

---

## 5. JIT (Just-In-Time Compiler)

**Definition**

* Converts **MSIL** into **Machine Code**.

**Important**

* JIT compiles a method **only when it is called for the first time**.
* If the same method is called again, it uses the already compiled Machine Code.

---

## 6. CPU

The CPU executes the generated **Machine Code**.

---

## 7. CLR (Common Language Runtime)

**Definition**

* The runtime environment responsible for executing .NET applications.

### CLR Responsibilities

1. Reads the MSIL.
2. Calls the JIT Compiler.
3. Executes the generated Machine Code.
4. Manages memory.
5. Runs the Garbage Collector (GC).
6. Handles exceptions.
7. Provides security services.

---

## 8. Garbage Collector (GC)

**Definition**

* Automatically removes objects that are no longer referenced to free memory.

---

## 9. DLL (Dynamic Link Library)

**Definition**

* A reusable code library used by other applications.
* Cannot usually run by itself.

A DLL also contains:

* MSIL
* Metadata
* Manifest

---

## 10. EXE vs DLL

| EXE                       | DLL                     |
| ------------------------- | ----------------------- |
| Executable program        | Reusable library        |
| Has an entry point (Main) | Usually has no Main     |
| Can run directly          | Used by another program |

---

## 11. Keywords to Remember

* **Compiler** → C# ➜ MSIL
* **JIT** → MSIL ➜ Machine Code
* **CLR** → Executes .NET applications
* **GC** → Cleans unused objects
* **CPU** → Executes Machine Code
* **DLL** → Reusable library
* **MSIL** → Intermediate Language

---

## Interview Notes

**Q:** Does the C# Compiler generate Machine Code directly?

**A:** No. It generates **MSIL**. The **JIT Compiler** converts MSIL into Machine Code at runtime.

---

### One-Line Summary

```
Compiler → MSIL → CLR → JIT → Machine Code → CPU
```
